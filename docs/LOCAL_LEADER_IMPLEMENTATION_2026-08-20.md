# تنفيذ القائد المحلي ووضع نموذج المحادثة الاختياري

**التاريخ:** 20 أغسطس 2026  
**الحالة:** منفذ ومختبر؛ تنزيل النموذج اختياري ويبدأ فقط بلمس المستخدم للزر.

## ما أضيف فعلياً

تحولت مساحة المساعد إلى **القائد المحلي**. القائد يعمل بلا شبكة من خلال قواعد المشروع وسجل مهام محلي، وينسق خمسة أدوار مرئية: القائد، القالب، الملابس، الجودة، والخصوصية. دور البحث لا يعمل تلقائياً ولا يرسل أي رسالة أو صورة إلى الخارج.

يدعم القائد الآن الإدخال النصي والصوتي الاختياري عبر محرك التعرف الذي يتيحه المتصفح، مع حقل نص ثابت عندما لا تتوفر الميزة أو يرفض إذن الميكروفون. كما أضيفت مرفقات شعار وتذييل: يختار المستخدم صورة من هاتفه، يرى معاينة، ثم يؤكد قبل وضعها في `TemplateSettings`. الصورة لا تدخل رسائل المحادثة ولا تغادر الجهاز؛ تحفظ فقط ضمن إعدادات القالب المحلية التي اختار المستخدم تطبيقها.

| القدرة | السلوك المحلي | حماية المستخدم |
|---|---|---|
| أمر تصميم مثل «كبّر الملابس» | ينشئ مهمة محددة وينتظر زر التأكيد. | لا تغيير صامت. |
| شعار أو تذييل | معاينة، ثم وضع داخل القالب وإعادة بناء محلية عند وجود إعلان. | لا حفظ في سجل المحادثة ولا إرسال شبكة. |
| الكلام | يحوّل الكلام إلى مسودة قابلة للتعديل حين يدعم المتصفح ذلك. | يبقى النص بديلاً دائماً. |
| سؤال أو خطة | يعطي القائد المحلي إرشاداً من قواعد المشروع. | لا يدّعي بحثاً خارجياً أو رؤية صور لم يرسلها المستخدم. |

## وضع النموذج المحلي القابل للتنزيل

أضيفت بطاقة اختيارية لـ **Llama 3.2 1B q4f16** عبر WebLLM. لا تُحمّل الأوزان عند فتح التطبيق ولا عند تثبيت PWA؛ يبدأ التنزيل فقط عندما يضغط المستخدم «تنزيل وتجربة» وبعد أن يعلن المتصفح دعم WebGPU. يعمل الاستدلال في Web Worker حتى لا تتجمد الواجهة، وتبقى قواعد القائد المحلية خطة رجوع عند فشل WebGPU أو امتلاء الذاكرة. يعرض الزر مسار حذف صريح لملفات النموذج بعد التجربة.

> نموذج WebLLM لا يضمن العمل على كل هاتف. السجل الرسمي للنموذج المحدد يذكر `879.04MB` من VRAM تقريباً؛ لذلك لا يوصف كشرط للتطبيق ولا كنموذج يعمل حتماً على الأجهزة الضعيفة. [1]

## ما لم يُفعل عمداً

لا توجد خمسة نماذج ضخمة تعمل معاً، ولا APK جديد، ولا خدمة سحابية أو مفتاح أو عملية خلفية. يوجد قائد محلي وخمسة أدوار منطقية، مع **نموذج واحد** اختياري عند توافق الهاتف. هذا يمنع استنزاف البطارية والذاكرة ويجعل المسار الأساسي صالحاً بلا إنترنت بعد تخزين التطبيق وموارده.

## التحقق

اجتازت التوسعة اختبارات القائد والأوامر والمحادثة ومسار Home. شغلت بوابة الجودة الكاملة بنجاح: **223 اختباراً في 56 ملفاً** وTypeScript والبناء وميزانية الأداء. استُبقيت CSS عند سقف 130KiB، وبقيت حزمة WebLLM البالغة نحو 6MiB ملف عامل منفصل لا يحمل إلا عند طلب النموذج.
