# بحث أولي عن موفّري المفاتيح المرشحين

**التاريخ:** 21 أغسطس 2026  
**الحالة:** بحث أولي فقط. لا يُحفظ أي مفتاح ولا يُفعّل أي مزود استناداً إلى هذا الملف.

| الاسم الذي ذكره المالك | النتيجة | قرار أولي |
|---|---|---|
| **ModelsLab** | توثق الجهة مفتاح API في جسم طلب JSON، ولها نقطة Fashion تتطلب `init_image` و`cloth_image` و`cloth_type` ومفتاح Enterprise؛ الردود 402 و403 تعني رصيداً غير كافٍ أو ميزة غير متاحة. [1] [2] | يمكن عرضه كمرشح Try-On خارجي **غير مفعّل** إلى أن يختبر المالك المفتاح والحصة بنفسه داخل الفاحص الخاص. لا تُرسل أي صورة قبل موافقة واضحة منفصلة. |
| **Free.ai** | توثق الجهة مفتاحاً يبدأ بـ `sk-free-` ورأس Bearer وكتالوجاً حياً في `/v1/models`، مع حصة مجانية يومية معلنة وخدمات نص وصور. [10] | أضيف إلى الفاحص الخاص فقط. الاستخدام المستقبلي للنص اختياري ومقيّد بالحصة؛ أما الصور فتحتاج موافقة مستقلة ولا تُرسل تلقائياً. |
| **LLM7 Dashboard** | LLM7 OpenAI-compatible عبر `https://api.llm7.io/v1`، وتوثق `/v1/models` ككتالوج حي. يذكر التوثيق وصولاً مجهولاً أو مفتاحاً من لوحة التحكم، ونماذج مجانية ومقيدة وخطط مدفوعة؛ لذلك صلاحية مفتاح لا تعني خدمة مجانية غير محدودة. [3] [4] | مرشح جيد للنص فقط كبديل اختياري للقائد المتصل، بعد تحديد صيغة المفتاح الرسمية أو اختيار المالك له من مصدره. لا يدخل في مسار الصور تلقائياً. |
| **LarpRouter** | يعلن الموقع أنه بوابة OpenAI-compatible للنماذج المتعددة ومفتاح واحد لكل مشروع، مع تجربة أولى ممولة ثم رصيد عند التوسع، لكنه لا يوفر في المصدر المقروء مرجع API يثبت عنواناً أو نقطة فحص. [5] | لا يُضاف اتصال تلقائي ولا تصنيف للصيغة بعد؛ يحتاج رابط صفحة التوثيق أو مفتاحاً يذكر مصدره داخل واجهة الفاحص. |
| **GitHub / Genesis Studio** | الاسم «Genesis Studio» غير محدد بمصدر رسمي كواجهة نماذج. أما GitHub Models نفسه فقد أوقف بالكامل في 30 يوليو 2026. يبقى GitHub PAT مفتاحاً لتطوير المستودعات وREST API وليس مفتاح نموذج. [6] [7] | لا يُستخدم كمزود نماذج. إن كان المفتاح GitHub PAT، يفحص فقط كتكامل تطوير منفصل وبأقل الصلاحيات، ولا يدخل في القائد أو توليد الصور. |
| **ByNara** | ظهرت إضافة ByNara AI لـ VS Code، لكن لم يظهر توثيق API رسمي يحدد خدمة عامة أو مصادقة أو نقطة تحقق. [8] | معلّق. يلزم رابط الموقع أو صفحة المفاتيح الرسمية قبل إضافته؛ لا نخمن الوجهة من اسم المفتاح. |

> يتطلب الفحص الآمن نقطة موثقة من الموفّر ولا يستخدم رابطاً يكتبه المستخدم. المفاتيح مجهولة الصيغة لا تغادر الفاحص الخاص. لا يحوّل نجاح الفحص أي مفتاح إلى مفتاح محفوظ أو مفعل.

## تحقق من روابط المرفق

فُحصت روابط المرفق من دون إدخال بيانات. صفحة إدارة مفاتيح NaraRouter تطلب تسجيل الدخول، في حين أن مسار `/key` الظاهر في المرفق يعيد صفحة غير موجودة؛ لذلك لا يمكن اعتباره وثيقة API. صفحة LLM7 للمفاتيح تتطلب تسجيل الدخول أيضاً. ظهر LarpRouter كواجهة بوابة نماذج، لكن لم يقدم المسار المذكور مرجع API قابلاً للقراءة يثبت طريقة التحقق؛ لهذا يبقى التكامل معه معلّقاً ولا يرسل إليه الفاحص أي مفتاح.

المستودع المشار إليه باسم **Genesis Studio** هو محرر صور منتجات يعمل محلياً في المتصفح، ويصرح بأنه لا يحتاج مفاتيح API؛ ليس مزود نماذج أو جهة مفاتيح. كما أظهر موقع **Free.ai** واجهة OpenAI-compatible عامة ونموذجاً لمفتاح يبدأ بـ `sk-free-`، مع حصة مجانية يومية معلنة؛ لكنه لم يكن ضمن القائمة الأولى ولا تضاف صيغته إلى الفاحص إلا بعد قراءة مرجع API الكامل وحدود الاستخدام والخصوصية.
