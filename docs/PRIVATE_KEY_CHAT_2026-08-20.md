# محادثة دفعة مفاتيح API الخاصة

**التاريخ:** 20 أغسطس 2026  
**الحالة:** أداة مطوّر خاصة داخل لوحة المطوّر؛ لا تحفظ المفاتيح الخام ولا تعرضها في النتائج أو السجل أو النسخة الاحتياطية.

## الغرض والحدود الصريحة

تسمح المحادثة بلصق حتى 40 مفتاحاً في دفعة واحدة من دون إدخال اسم موقع. لا يمكن لتطبيق ويب التحقق من مفتاح دون وصول الخادم إليه لحظياً، ولذلك تنتقل القيمة عبر طلب الجلسة المحمي إلى الخادم **لوقت الفحص فقط**. لا يكتب الخادم القيمة في قاعدة البيانات أو التخزين المحلي أو السجل التشخيصي أو استجابة tRPC، ثم يعيد نتيجة موجزة خالية من القيمة أو القناع أو البصمة أو بيانات الحساب.

> لا ترسل المفاتيح في محادثة الدعم أو داخل GitHub أو لقطة شاشة. ألصقها حصراً في «محادثة المفاتيح الخاصة» بعد دخول لوحة المطوّر، ثم امسح جلسة المتصفح من زر الحذف عند الانتهاء.

## سياسة التصنيف والإرسال

| الحالة | التصرف | ما يراه المالك |
|---|---|---|
| صيغة معروفة | يرسل طلب `GET` واحداً إلى نقطة HTTPS ثابتة تخص الموفّر | اسم الموفّر وحالة صالح/مرفوض/مقيّد/تعذر الفحص واستخدامات مقترحة |
| صيغة غير معروفة أو عامة | لا يرسل المفتاح إلى أي جهة خارجية | «موفّر غير معروف» من دون عرض القيمة |
| تجاوز الحصة أو 429 | لا يعيد المحاولة | «مقيّد»؛ لا يعني أن المفتاح غير صالح |
| خطأ شبكة أو مهلة 8 ثوان | لا يعيد المحاولة | «تعذر الفحص» |

ينفذ الفحص بحد أقصى أربع طلبات متوازية لحماية حصة الحسابات، وبحد أقصى 40 مفتاحاً في الدفعة. لا يوجد حقل رابط حر، لذلك لا يمكن استخدام المحادثة كممر إلى عناوين داخلية أو إلى وجهة يكتبها المستخدم.

## الموفّرون المعرفون في النسخة الأولى

| الصيغة المتعرّف إليها محلياً | موفّر التحقق | الاستخدام المقترح في هذا المشروع |
|---|---|---|
| `AIza…` | Google Gemini API | القائد المتصل للنصوص والتخطيط، مع بقاء الصور محلية وعدم إرسالها تلقائياً. تدعم واجهة Gemini نماذج نص وصور وصوت، لكن صلاحية المفتاح لا تعني توافر كل نموذج أو حصة مجانية. [1] |
| `hf_…` | Hugging Face | الوصول المقيد إلى ملفات أو مزود استدلال متاح في حسابه. توصي Hugging Face بالمفاتيح الدقيقة الصلاحيات وبفصل المفتاح لكل استخدام. [2] |
| `sk-or-v1-…` | OpenRouter | بوابة بدائل نصية متصلة للقائد عند توافر رصيد ونموذج مناسب؛ التوثيق يؤكد استخدام Bearer وأن المفاتيح ذات قدرة عالية، لذا لا تحفظ تلقائياً. [3] |
| `gsk_…` | Groq | ردود نصية سريعة أو بديل متصل عند وجود حصة؛ لا يفعّل المفتاح أي مزود تلقائياً. [4] |
| `r8_…` | Replicate | تقييم نماذج صور منفصل عند وجود رصيد؛ توثيق Replicate يطلب Bearer ويتيح طلب بيانات الحساب الموثق. [5] |

المفاتيح التي تبدأ بصيغة عامة مثل `sk-…` لا تُخمن ولا تُرسل، لأن الصيغة وحدها لا تميّز مزودها بأمان. يمكن توسيع قائمة الصيغ مستقبلاً فقط بعد تثبيت نقطة تحقق رسمية وآمنة لذلك الموفّر.

## ما لا تفعله الأداة

الأداة لا تحفظ المفتاح للاستخدام اللاحق، ولا تنشئ مزوداً مفعلاً، ولا تشتري رصيداً، ولا تستنتج مستوى مجاني أو حقوق استخدام من رد الفحص وحده. بعد معرفة مفتاح صالح، يبقى قرار حفظه المشفّر داخل قسم «إدارة الذكاء الاصطناعي» قراراً منفصلاً وواضحاً للمالك.

## التحقق البرمجي

تغطي اختبارات الانحدار التعرف على الصيغ الخمس، وترك المجهول بلا أي اتصال خارجي، وعدم إعادة القيمة أو نص استجابة الموفّر، وحالات 401/403 و402/429، وحدّ حجم الدفعة والتوازي، وحماية إجراء tRPC، ومسح حقل المحادثة المرئي فور الإرسال. اجتازت النسخة 238 اختباراً في 62 ملف اختبار مع TypeScript والبناء وميزانية الأداء وفحص الهاتف.
