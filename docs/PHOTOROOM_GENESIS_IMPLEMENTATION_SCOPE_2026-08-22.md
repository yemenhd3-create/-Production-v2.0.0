# حزمة تحرير المنتج والاستديو المحلي

**التاريخ:** 22 أغسطس 2026  
**النطاق:** تنفيذ أصلي داخل مولد إعلانات الملابس، مستلهم وظيفياً من مزايا معلنة في Photoroom ومن وصف Genesis Studio العام. لم يُنسخ كود أو واجهة أو أصل بصري من أي مصدر خارجي.

## خريطة التنفيذ

| المجال | الحالة في المشروع | التنفيذ أو الحد |
|---|---|---|
| إزالة الخلفية | موجود ومحلي | يظل U2NetP هو المسار الأساسي؛ يستطيع استوديو التنقيح تشغيله قبل إدخال الصورة إلى القالب. |
| تنظيف الحواف | منفذ محلياً | ممحاة ناعمة أو حادة، واستعادة من الصورة الأصلية، مع تراجع وإعادة ضبط. |
| تحديد البقايا | منفذ محلياً | عصا لون لمنطقة متصلة وحد تسامح، وتحديد حر Lasso ثم حذف شفاف. لا توجد إعادة رسم أو Inpainting مخفي. |
| تحسين الألوان | منفذ محلياً | سطوع وتباين وتشبع مع تثبيت صريح للتعديل. |
| خلفيات ومنظر استديو | منفذ محلياً | خلفيات تلقائية وناعمة ودافئة وباردة وإضاءة داخل منطقة المنتج، إضافة إلى ظل ناعم أو ثابت. |
| قوالب ومقاسات اجتماعية | موجود | خمسة مقاسات نشر وقوالب وهوية وشارات وتذييل، مع تصدير PNG ومشاركة. |
| معالجة دفعات | موجود | حتى 10 صور؛ تخزين مؤقت محلي ومعالجة متوازية آمنة وإعادة محاولة وتصدير لكل نتيجة. |
| توليد خلفيات أو صور جديد | غير مفعّل تلقائياً | يتطلب مزود صور خارجي وحصة وسياسة صور واضحة؛ لا يرسل الاستوديو الصور إلى مزودي النص المتصلين. |
| رتوش Inpainting أو إصلاح عيوب مولّد | غير مفعّل | لا يوجد نموذج محلي خفيف موثوق لهذا الغرض على الهاتف؛ لا يعرض التطبيق ادعاءً زائفاً عن «إصلاح ذكي». |
| فيديو، تعاون متعدد المستخدمين، ومكتبة أصول سحابية | خارج هذا الإصدار | تحتاج تخزيناً وصلاحيات وحصص/بنية خلفية مستقلة، وليست بديلاً محلياً مكافئاً. |

## الخصوصية والأداء

يعمل الاستوديو في المتصفح. لا يرسل الصورة عند استخدام أدوات الفرشاة أو العصا أو Lasso أو ضبط الألوان أو الخلفيات والظلال. يحد الاستوديو الضلع الأطول إلى 1440 بكسل أثناء التنقيح كي يبقى مناسباً للهاتف، بينما يظل إخراج الإعلان النهائي بالمقاس الذي اختاره المستخدم. تُطبق التعديلات فقط بعد زر **استخدام الصورة المنقحة**.

## الاختبارات

تغطي اختبارات المنطق تحديد الألوان المتصل وLasso ومسح alpha، وتغطي اختبارات Canvas الخلفية والظل الجديدين. تظل إزالة الخلفية ذاتها خاضعة لاختبارات المسار المحلي القائمة.
