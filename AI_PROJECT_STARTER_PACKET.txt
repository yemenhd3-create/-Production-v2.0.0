## ما هو مكتمل — لا تكرره

1. مسار فردي ودفعة حتى 10 صور، قص حر، وإزالة خلفية محلية دون إنترنت بعد التنزيل الأول.
2. Canvas عربي RTL بخمسة مقاسات، شعار وتذييل وشارات وإعدادات قالب.
3. نصوص تسويقية محلية وواتساب ومشاركة وحفظ وPWA.
4. لوحة مطور وإدارة مزودي AI ورسائل وإدارة مستخدمين.
5. مصمم محلي ذكي: تحليل صورة خفيف، ثلاثة تخطيطات، درجات وأسباب، قص وألوان وتحويل للقطعة.
6. معاينة Canvas قبل/بعد، قبول أو تجاهل أو تراجع، وتفضيلات محلية قابلة للمسح.
7. اعتماد أو تجاهل مستقلان للاقتراح في كل عنصر دفعة.
8. جواز تصميم محلي اختياري بعد الرسم: يفحص أبعاد الناتج وتجانس المحتوى والسطوع، وينشئ بصمة SHA-256 وJSON قابل للتنزيل؛ لا يقبل إلا نتائج `blob:` أو `data:image/` ولا يرسل بيانات إلى الشبكة.
9. Quality Gate للتصدير محلياً: يبني على `DesignContract` و`DesignBenchmark` ويمنع الحفظ أو المشاركة عند الخطأ الهندسي الحرج فقط. التحذيرات، ومنها طول النص العربي والتباين المقدّر، لا تمنع التصدير. راجع `client/src/lib/designQualityGate.ts` و`server/designQualityGate.test.ts`.
10. Pixel Truth Gate v1: يفحص بكسلات الإعلان النهائي المحلي بعد الرسم في مناطق العنوان والسعر والتذييل، ويصنف التباين إلى `PASS` و`WARNING` و`BLOCK`. لا يُسمح بإعادة اقتراح فحص نظري للألوان بدلاً منه؛ راجع `client/src/lib/pixelTruthGate.ts` و`server/pixelTruthGate.test.ts`.
11. Visual Repair Loop v1 للعنوان فقط: يعيد رسم PNG عبر المحرك الحالي بعد إصلاح خلفية العنوان، ثم يعيد فحص Pixel Truth والعقد وبوابة الجودة قبل قبول النتيجة. إذا بقي `BLOCK` يحافظ على الإعلان الأصلي، وUndo يعيد Snapshot محلياً في الذاكرة؛ راجع `client/src/pages/Home.tsx` و`server/homeWorkflow.test.ts`.
12. Theme Registry v1: خمسة أنماط بصرية محلية (`classic`, `midnight`, `rose`, `mint`, `sand`) مستقلة عن المقاسات، يستهلكها Canvas الحالي وتُحفظ في وثيقة التصميم وسجل Replay. راجع `shared/templateThemes.ts` و`server/templateThemes.test.ts`.
13. رموز الدخول: مسار دخول بديل داخل التطبيق صادر من لوحة المطور، لا يغيّر بوابة Manus الخارجية. الرمز لا يُخزّن خاماً، وتكون له صلاحية وتعداد استخدام اختياريان وإبطال فوري؛ راجع `server/accessCodes.ts` و`server/accessCodes.test.ts` و`server/accessCodeRouter.test.ts`.
14. تحكم حجم المنتج: يبدأ محرك Canvas بحجم مرئي محسّن 115% لمسار القطعة المستقلة، وتظهر بطاقة «حجم المنتج» مباشرة بعد التوليد (85%–150% مع زري أصغر/أكبر). يعاد الرسم من المصدر المحلي الجاهز فقط ولا تعاد إزالة الخلفية. يبقى القص داخل منطقة البطل الآمنة، ويحفظ الحجم في `TemplateSettings` و`DesignDocument` وDesign Replay؛ راجع `client/src/lib/canvasRenderer.ts` و`server/canvasRenderer.test.ts` و`server/homeWorkflow.test.ts`.

# مولد إعلانات الملابس — Marwan Designer

تطبيق ويب عربي موجّه للهاتف لتحويل **صورة قطعة ملابس** إلى إعلان جاهز للتنزيل والمشاركة. المشروع **شخصي وتعليمي وغير تجاري**، ويعتمد على Canvas محلياً لإنشاء الإعلان؛ أما تجربة الملابس بالذكاء الاصطناعي فهي طبقة اختيارية لا توقف التطبيق عند عدم توفرها.

## تجربة الاستخدام

| المرحلة | ما يفعله المستخدم | النتيجة |
|---|---|---|
| 1. رفع الملابس | يختار صورة القطعة بصيغة JPG أو PNG أو WebP. | ينتقل مباشرةً إلى بيانات الإعلان. |
| 2. بيانات الإعلان | يضيف الاسم والعنوان والخصم والسعر والكمية والألوان والمزايا وبيانات المتجر، وكلها اختيارية. | يضغط **توليد الإعلان** مرة واحدة. |
| 3. الإعلان النهائي | يراجع النتيجة ثم ينزّل PNG أو يشارك أو يفتح واتساب أو يعدّل البيانات. | إعلان عربي عمودي قابل للمشاركة. |

> عند عدم توفر مزود Try‑On أو فشله، يستخدم التطبيق صورة القطعة الأصلية تلقائياً داخل القالب ويظهر تنبيهاً واضحاً للمستخدم. لا يفشل إنشاء الإعلان بسبب الذكاء الاصطناعي.

## الميزات المنفذة

| المجال | التنفيذ الحالي |
|---|---|
| واجهة الهاتف | RTL كامل، خطوط عربية، أزرار كبيرة، ثلاث مراحل واضحة، وتنقل سفلي: إنشاء، إعدادات، مطور. |
| القالب | Canvas عربي بمقاس منشور عمودي **1080×1350** أو قصة/حالة **1080×1920**، مع شارة خصم وشريط متجر اختياري. |
| الإعدادات | إظهار أو إخفاء اسم المنتج، العنوان، الخصم، الكمية، الألوان، المزايا، السعر، ومعلومات المتجر. |
| Try‑On | مؤجل بطلب المالك؛ يبقى القص وإزالة الخلفية المحلية وCanvas والتصدير هي رحلة المستخدم الحالية. |
| لوحة المطور | دخول خادمي باسم مستخدم وكلمة مرور، إدارة مزودي AI، فحص الاتصال، وسجل تشخيصي. |
| الحماية | مفاتيح المزودين مشفّرة على الخادم ولا تُعاد إلى واجهة المستخدم أو تحفظ في Git. |
| المشاركة | تنزيل PNG، مشاركة من الهاتف عبر Web Share عند توفرها، وبديل واتساب بالنص التسويقي. |
| PWA | manifest وعامل خدمة للتثبيت والعمل دون اتصال في القلب المحلي. |

## إعداد لوحة المطور

لا تُكتب بيانات الدخول أو مفاتيح API داخل الملفات أو في GitHub. تُضاف بيانات لوحة المطور كأسرار في بيئة النشر فقط:

| المتغير | الغرض |
|---|---|
| `DEVELOPER_PANEL_USERNAME` | اسم مستخدم لوحة المطور. |
| `DEVELOPER_PANEL_PASSWORD` | كلمة مرور لوحة المطور. |
| `JWT_SECRET` | حماية جلسة المطور الموقعة. |

بعد الدخول إلى **المطور**، يمكن إدارة مزودات اختيارية ثم اختبار الاتصال عند إعادة فتح مرحلتها. يبقى المفتاح مشفراً على الخادم؛ وتعرض الواجهة اسم المزود وحالته فقط.

## تجربة الملابس بالذكاء الاصطناعي

وضع Try-On مؤجل حالياً بطلب المالك ولا يدخل في رحلة المستخدم العادية. عند إعادة فتحه مستقبلاً، يجب اختيار مزود مرخّص واختبار محدود داخل لوحة المطور؛ عدم إضافة مزود لا يمنع استعمال التطبيق، إذ يستمر القالب المحلي في العمل بصورة القطعة بعد إزالة الخلفية محلياً.

## الخصوصية والحدود

لا تتضمن الشيفرة مفاتيح API أو كلمات مرور إنتاجية. لا يستخدم التطبيق صور العميل بعد انتهاء جلسة المتصفح في المسار المحلي. لا يقدم التخزين المحلي حماية مكافئة لخزنة أسرار خادمية؛ لذلك تحفظ مفاتيح مزود AI على الخادم فقط.

## المراجعة والمساهمة

import { int, mysqlEnum, mysqlTable, text, timestamp, varchar } from "drizzle-orm/mysql-core";

/**
 * Core user table backing auth flow.
 * Extend this file with additional tables as your product grows.
 * Columns use camelCase to match both database fields and generated types.
 */
export const users = mysqlTable("users", {
  /**
   * Surrogate primary key. Auto-incremented numeric value managed by the database.
   * Use this for relations between tables.
   */
  id: int("id").autoincrement().primaryKey(),
  /** Manus OAuth identifier (openId) returned from the OAuth callback. Unique per user. */
  openId: varchar("openId", { length: 64 }).notNull().unique(),
  name: text("name"),
  email: varchar("email", { length: 320 }),
  loginMethod: varchar("loginMethod", { length: 64 }),
  role: mysqlEnum("role", ["user", "admin"]).default("user").notNull(),
  isDisabled: int("isDisabled").default(0).notNull(),
  createdAt: timestamp("createdAt").defaultNow().notNull(),
  updatedAt: timestamp("updatedAt").defaultNow().onUpdateNow().notNull(),
  lastSignedIn: timestamp("lastSignedIn").defaultNow().notNull(),
});

export type User = typeof users.$inferSelect;
export type InsertUser = typeof users.$inferInsert;

/** Encrypted credentials are never sent back to the browser once saved. */
export const developerProviders = mysqlTable("developer_providers", {
  id: varchar("id", { length: 64 }).primaryKey(),
  name: varchar("name", { length: 120 }).notNull(),
  baseUrl: varchar("baseUrl", { length: 500 }).notNull(),
  model: varchar("model", { length: 160 }).notNull(),
  encryptedApiKey: text("encryptedApiKey").notNull(),
  isEnabled: int("isEnabled").default(1).notNull(),
  createdAt: timestamp("createdAt").defaultNow().notNull(),
  updatedAt: timestamp("updatedAt").defaultNow().onUpdateNow().notNull(),
});

export type DeveloperProvider = typeof developerProviders.$inferSelect;

/** رسالة عامة يحررها المطور وتظهر للحسابات المفعّلة فقط. */
export const appAnnouncements = mysqlTable("app_announcements", {
  id: int("id").autoincrement().primaryKey(),
  message: text("message").notNull(),
  isActive: int("isActive").default(1).notNull(),
  createdAt: timestamp("createdAt").defaultNow().notNull(),

    status: publicProcedure.query(({ ctx }) => ({ authenticated: isDeveloperSession(ctx.req) })),
