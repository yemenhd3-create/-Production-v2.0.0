# 🎨 مولد إعلانات الملابس الاحترافي

تطبيق ويب ذكي لتوليد إعلانات الملابس بشكل تلقائي وسريع، موجّه للمتاجر العربية مع دعم كامل لاتجاه RTL.

## ✨ الميزات الرئيسية

### 1. **توليد الإعلانات الاحترافية**
- صور بأبعاد احترافية (1080×1350 بكسل)
- شارة خصم على شكل درع
- لوحة أسعار ملونة
- شريط تذييل بمعلومات المتجر
- خلفية بيضاء نظيفة

### 2. **الذكاء الاصطناعي المدمج**
- توليد نصوص تسويقية احترافية باستخدام **Kimi K3**
- توليد صور للمنتجات باستخدام **AIML API**
- استخراج الكلمات المفتاحية تلقائياً
- توليد عناوين جذابة

### 3. **إدارة البيانات الآمنة**
- حفظ محلي مشفر للبيانات
- نظام رموز اشتراكات آمن
- إدارة نماذج ذكاء اصطناعي متعددة
- بدون مفاتيح API مدمجة

### 4. **المشاركة والتنزيل**
- مشاركة فورية عبر **واتساب**
- مشاركة عبر **البريد الإلكتروني**
- نسخ الصور والنصوص
- تنزيل بجودة عالية (PNG)

### 5. **تطبيق ويب متقدم (PWA)**
- تثبيت التطبيق على الهاتف
- العمل بدون اتصال بالإنترنت
- Service Worker للتخزين المؤقت
- واجهة عربية RTL كاملة

### 6. **لوحة مطور محمية**
- حماية مزدوجة (كلمة مرور + مفتاح وصول)
- أدوات تطوير متقدمة
- إدارة البيانات المحلية
- تصدير واستيراد البيانات

## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- pnpm أو npm
- متصفح حديث

### التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/yourusername/clothing-ad-generator-pro.git
cd clothing-ad-generator-pro

# تثبيت المتطلبات
pnpm install

# إنشاء ملف .env.local
cp .env.local.example .env.local

# تشغيل خادم التطوير
pnpm dev
```

### الوصول إلى التطبيق
```
http://localhost:3000
```

## 📋 خطوات الاستخدام

### 1. **رفع الصورة**
- اسحب صورة المنتج أو اضغط لاختيارها
- يدعم JPG, PNG, WebP (الحد الأقصى 10 ميجابايت)

### 2. **إدخال البيانات**
- اسم المنتج
- العنوان الفرعي
- اسم المتجر
- السعر القديم والجديد
- الموسم والألوان والمقاسات

### 3. **الإعدادات**
- معلومات المتجر (الهاتف، الموقع)
- نماذج الذكاء الاصطناعي (API keys)
- الألوان والخطوط

### 4. **المعاينة والنشر**
- معاينة الإعلان قبل النشر
- توليد النصوص بالذكاء الاصطناعي
- مشاركة فوراً عبر واتساب

## 🛠️ التقنيات المستخدمة

### Frontend
- **React 19** - مكتبة UI
- **TypeScript** - لغة برمجة آمنة
- **Tailwind CSS 4** - تصاميم
- **Canvas API** - توليد الصور

### Backend
- **Express.js** - خادم ويب
- **tRPC** - اتصال آمن
- **MySQL/TiDB** - قاعدة بيانات

### AI & Services
- **Kimi K3** - توليد النصوص
- **AIML API** - توليد الصور
- **localStorage** - تخزين محلي

### PWA
- **Service Worker** - عمل بدون اتصال
- **Web Manifest** - معلومات التطبيق
- **Offline Support** - دعم العمل بدون إنترنت
