# مولد إعلانات الملابس — Marwan Designer

تطبيق ويب عربي موجّه للهاتف لتحويل **صورة قطعة ملابس** إلى إعلان جاهز للتنزيل والمشاركة. المشروع **شخصي وتعليمي وغير تجاري**، ويعتمد على Canvas محلياً لإنشاء الإعلان؛ أما تجربة الملابس بالذكاء الاصطناعي فهي طبقة اختيارية لا توقف التطبيق عند عدم توفرها.

## تجربة الاستخدام

| المرحلة | ما يفعله المستخدم | النتيجة |
|---|---|---|
| 1. رفع الملابس | يختار صورة القطعة بصيغة JPG أو PNG أو WebP. | ينتقل مباشرةً إلى بيانات الإعلان. |
| 2. بيانات الإعلان | يضيف الاسم والعنوان والخصم والسعر والكمية والألوان والمزايا وبيانات المتجر، وكلها اختيارية. | يضغط **توليد الإعلان** مرة واحدة. |
| 3. الإعلان النهائي | يراجع النتيجة ثم ينزّل PNG أو يشارك أو يفتح واتساب أو يعدّل البيانات. | إعلان عربي عمودي قابل للمشاركة. |

> عند عدم توفر مزود Try‑On أو فشله، يستخدم التطبيق صورة القطعة الأصلية تلقائياً داخل القالب ويظهر تنبيهاً واضحاً للمستخدم. لا يفشل إنشاء الإعلان بسبب الذكاء الاصطناعي.

## الميزات المنفذة

| المجال | التنفيذ الحالي |
|---|---|
| واجهة الهاتف | RTL كامل، خطوط عربية، أزرار كبيرة، ثلاث مراحل واضحة، وتنقل سفلي: إنشاء، إعدادات، مطور. |
| القالب | Canvas عربي بمقاس منشور عمودي **1080×1350** أو قصة/حالة **1080×1920**، مع شارة خصم وشريط متجر اختياري. |
| الإعدادات | إظهار أو إخفاء اسم المنتج، العنوان، الخصم، الكمية، الألوان، المزايا، السعر، ومعلومات المتجر. |
| Try‑On | موصل خادمي اختياري لمسار Product to Model من FASHN مع استطلاع حالة النتيجة وخطة رجوع محلية. |
| لوحة المطور | دخول خادمي باسم مستخدم وكلمة مرور، إدارة مزودي AI، فحص الاتصال، وسجل تشخيصي. |
| الحماية | مفاتيح المزودين مشفّرة على الخادم ولا تُعاد إلى واجهة المستخدم أو تحفظ في Git. |
| المشاركة | تنزيل PNG، مشاركة من الهاتف عبر Web Share عند توفرها، وبديل واتساب بالنص التسويقي. |
| PWA | manifest وعامل خدمة للتثبيت والعمل دون اتصال في القلب المحلي. |

## بنية المشروع

```text
client/src/
  pages/Home.tsx                 # مسار الإنشاء والمشاركة
  components/                    # الرفع، بيانات الإعلان، الإعدادات، المطور، حول التطبيق
  lib/canvasRenderer.ts          # قالب Canvas والتصدير
  lib/share.ts                   # التنزيل والمشاركة
server/
  routers.ts                     # إجراءات tRPC
  tryOn.ts                       # الموصل السحابي الاختياري
  developerAuth.ts               # مصادقة لوحة المطور
  developerProviders.ts          # تشفير وإدارة المزودين
shared/
  adWorkflow.ts                  # قرار النجاح أو الرجوع المحلي
  types.ts                       # عقود البيانات المشتركة
drizzle/
  schema.ts                      # جداول المزودين المشفرة
```

## التشغيل محلياً

يتطلب المشروع Node.js 18 أو أحدث وpnpm. على الهاتف يمكن تشغيل أوامر Git وNode عبر Termux عند توافر بيئة مناسبة.

```bash
git clone https://github.com/yemenhd3-create/-Production-v2.0.0.git
cd clothing-ad-generator-pro
pnpm install
pnpm dev
```

ثم افتح الرابط الذي يطبعه الخادم. للتحقق قبل النشر:

```bash
pnpm test
pnpm check
pnpm build
```

## إعداد لوحة المطور

لا تُكتب بيانات الدخول أو مفاتيح API داخل الملفات أو في GitHub. تُضاف بيانات لوحة المطور كأسرار في بيئة النشر فقط:

| المتغير | الغرض |
|---|---|
| `DEVELOPER_PANEL_USERNAME` | اسم مستخدم لوحة المطور. |
| `DEVELOPER_PANEL_PASSWORD` | كلمة مرور لوحة المطور. |
| `JWT_SECRET` | حماية جلسة المطور الموقعة. |

بعد الدخول إلى **المطور**، أضف مزوداً مثل FASHN ثم اختبر الاتصال. يبقى المفتاح مشفراً على الخادم؛ وتعرض الواجهة اسم المزود وحالته فقط.

## تجربة الملابس بالذكاء الاصطناعي

الموصل الحالي مهيأ لمزود FASHN الاختياري ومسار Product to Model، وهو مناسب لفكرة تحويل صورة المنتج إلى عرض على نموذج. راجع الوثائق الرسمية قبل إدخال مفتاح مزودك: [FASHN API documentation](https://docs.fashn.ai/). عدم إضافة مزود لا يمنع استعمال التطبيق؛ سيستمر القالب المحلي في العمل بصورة القطعة الأصلية.

## الخصوصية والحدود

لا تتضمن الشيفرة مفاتيح API أو كلمات مرور إنتاجية. لا يستخدم التطبيق صور العميل بعد انتهاء جلسة المتصفح في المسار المحلي. لا يقدم التخزين المحلي حماية مكافئة لخزنة أسرار خادمية؛ لذلك تحفظ مفاتيح مزود AI على الخادم فقط.
