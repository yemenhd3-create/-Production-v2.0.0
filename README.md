# Clothing Ad Generator v2.0.0

مجاني، مفتوح المصدر، وOffline-First لمراكز الملابس.

## التشغيل
```bash
npm test
npm run check
cp .env.example .env
npm start
```
في الإنتاج: ضع `NODE_ENV=production` و`DEVELOPER_SECRET` قويًا (32 حرفًا أو أكثر).

## فلسفة المشروع
القلب الأساسي يعمل بدون إنترنت وبدون AI: رفع صورة، معالجة محلية، قالب، بيانات المنتج، هوية المركز، وناتج PNG.

AI اختياري فقط للنص التسويقي وVirtual Try-On عند توفر مزود مناسب.

## التفعيل
أول تفعيل Online. الخادم يصدر Signed Token بتوقيع Ed25519. المتصفح يتحقق من التوقيع محليًا ويستمر Offline حتى انتهاء المدة. لا يوجد bypass يعتبر رمزًا نصيًا عاديًا صالحًا.

## AI
يمكن إضافة عدد غير محدود من المزودين والمفاتيح. يمكن تحديد مزود نشط، مع fallback إلى المزودين الآخرين. مفاتيح API مشفرة محليًا باستخدام Web Crypto عندما يتوفر.

## الخصوصية
المسار المحلي لا يرفع صور المستخدم إلى خادم المشروع. استخدام AI قد يرسل الصور/البيانات إلى مزود AI الذي اختاره المستخدم.
